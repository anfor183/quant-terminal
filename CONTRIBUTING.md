# Contributing

Public contributions are welcome through forks and pull requests.

1. Fork this repository into your own GitHub account.
2. Create a branch in your fork and make your changes there.
3. Open a pull request against this repository.

The main branch is maintained by the repository owner. Public contributors do not receive write access. Pull requests are proposals and are not merged automatically. Community reviews are welcome, but votes or approvals do not grant permission to change main.

Never include account credentials, API keys, or files from the data directory.
